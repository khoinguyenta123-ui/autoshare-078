# THINKING PROCESS

Before writing the prompt, imagine the final image.

Ask yourself:

What is the first thing the viewer sees?

Where should the eye move next?

Is there visual clutter?

Can anything be removed?

Does the image communicate the insight within two seconds?

Only then write the prompt.
